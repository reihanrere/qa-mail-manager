Email tes untuk Gmail

Kirim dari Gmail ke alamat @re-testing.me yang sudah di-generate. Tiap email menguji bagian berbeda dari message detail.

  1. Di Gmail klik Compose, isi To dengan alamat akun.
  2. Klik Copy subject, paste ke kolom Subject.
  3. Klik Copy body, paste (Cmd+V) ke isi email. Format, tabel, link, dan gambar ikut.
  4. Send, lalu buka Inbox di app.

1. OTP + HTML lengkap

Menguji: OTP card (482913, format terpisah "482 913") + tombol copy, HTML di iframe, tabel, tombol link (buka tab baru), gambar lebar mengecil, URL panjang tidak overflow, emoji & karakter khusus di subject.

Subject[Tokopedia] Kode verifikasi akun kamu ✅ Jangan bagikan ke pihak manapun, termasuk CS Tokopedia
Body

Halo Rinda 👋

Gunakan kode verifikasi berikut untuk masuk: 482 913

4 8 2 9 1 3

Verifikasi Sekarang

Link teks biasa: Pusat Bantuan, harus terbuka di tab baru.

URL panjang: https://example.com/a/very/long/path/that/keeps/going/and/going/without/any/spaces/to/check/the/layout/does/not/overflow?with=query&and=more

  • Karakter khusus: <script> & "kutip" © €
  • Emoji: 🎉 ✅ 🚀

Jika kamu tidak meminta kode ini, abaikan email ini.

2. OTP alfanumerik, teks polos

Menguji: OTP huruf+angka (A7K9Q2), tampilan teks tanpa HTML, baris & indentasi tetap, baris panjang dibungkus.

SubjectYour sign-in verification code
Body
Hey there! Your verification code is: A7K9Q2 Line breaks should be preserved: - indented line 1 - indented line 2 Long line: aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa Thanks, The GitHub Team

Gmail tetap mengirim versi HTML. Untuk benar-benar tanpa HTML: di jendela Compose klik ⋮ (More options) → Plain text mode sebelum paste.

3. Newsletter, tanpa OTP, dengan lampiran

Menguji: angka biasa (tahun, harga, telepon, nomor order) tidak muncul sebagai OTP, tabel, gambar, lampiran dilewati tanpa error.

SubjectFlash Sale 10.10 - diskon sampai 90% hanya tahun 2026
Body

Flash Sale 10.10 🔥

Tahun 2026, harga Rp 150.000, telepon 0812 3456 7890, order #20261010.

Lampirkan file PDF atau gambar apa saja di Gmail (ikon 📎) untuk menguji lampiran.

4. OTP dengan tanda hubung + aksen

Menguji: format OTP "735-208" jadi 735208, karakter beraksen (é è à ç ü ñ).

SubjectVotre code de sécurité
Body

Bonjour,

Votre security code est 735-208.

Caractères accentués : é è à ç ü ñ

Merci.

5. Tanpa subject, tanpa isi

Menguji: "(No subject)" dan "This message has no readable content". Gmail akan bertanya "Send without subject?" → OK.

Kosongkan Subject dan isi email, lalu Send.
